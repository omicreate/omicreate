# omicreate

小さくて役に立つツールを、AIエージェントと一緒に作っています。
企画からコード・動画制作までの過程は、リポジトリとコミットログにそのまま残しています。

*Solo developer in Japan, building small useful tools together with AI agents — from planning to code.*
