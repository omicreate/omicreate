## 2. 直さなかった指摘

- 来店日が過去の記録でまたねカードを出さない（上の表のとおり意図した動き）
- OS の文字サイズ設定に合わせて文字が大きくならない。全体の px を rem に置き換える必要があり、実機で確かめてから決める

## 3. 未検証のこと

- iPhone（Safari・ホーム画面に追加した状態）と Android の実機での動作。確かめたのは Playwright の Chromium だけ
- 日付欄の表示順（Chromium のテスト環境では月/日/年の順に出た。日本語設定の端末なら年/月/日になるはず）
- 下書きの「画面を離れる瞬間の保存」（pagehide）。0.3秒後の自動保存は E2E で確認済み
- 暗号化バックアップの 600,000 回の鍵の計算が、性能の低いスマホで何秒かかるか（処理中の表示は入れてある）
- 更新が入るとページが自動で読み込み直される（入力途中の内容は下書きとして残る）。読み込み直す前に聞くかは未決
- 来店記録が二重入力でも続くか（仕様 11章の最大の未検証の前提。試用で測る）
