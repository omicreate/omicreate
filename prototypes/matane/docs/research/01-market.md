# 市場と統計：日本の個人美容師（1人サロン・フリーランス・業務委託・シェアサロン）

調査日: 2026-11-07 / 担当キー: `market`

種別の凡例: **fact**＝出典を実際に開いて確認 / **estimate**＝推定・計算 / **unverified**＝検索結果の要約のみで本文は未確認

## 1. 要点（先に結論）

- 美容所は **28万1,687施設**、従業美容師は **59万6,942人**（2026年3月末）。どちらも毎年1.3〜1.5%ずつ増えている。1施設あたり約2.1人で、この比率は10年以上ほぼ変わらない。【fact／比率は estimate】
- 小規模化が進んでいる。従業者5人未満の事業者は **86.7%**（令和5年度調査。平成27年度は78.2%）。従業者1人の施設は、平成22年度に29.9%、平成27年度に約32%だった。【fact】
- 一方、美容室の市場（消費者側の推計）は **1兆3,063億円で前年比−5.9%**（美容センサス2026年上期）。単価はほぼ横ばいで、**利用率と来店回数の減少**が縮小の原因。施設が増えて市場が縮んだため、1施設あたりの需要は前年より約7%減ったと推計される。【fact／1施設あたりは estimate】
- 倒産は過去最多の水準にある（TDB：2025年は235件。業歴10年未満が49.0%、平均業歴13.0年で「短命化」）。2026年度上半期は前年をやや下回った（TSR：54件）。【fact】
- アプリが取り組むべき課題は、①**来店間隔が延びていること（再来）**、②**顧客数の減少**、③**値上げが難しいこと**、④**個人で回せる顧客管理**の4点。課金できる余地は小さいので、売上の増加で元が取れることを示せる低価格の設計が前提になる。【estimate】

| 年間賞与 | 10万6,700円 | 同上 |
| 年収換算 | **388.5万円**（30.0歳、勤続6.8年、企業規模10人以上） | 同上（令和7年賃金構造基本統計調査、2026/3/24公表） |
| 美容師（ヘア）の仕事からの年収（自己申告） | 平均370.0万円（2023年実績、n=475。前年は538.1万円で年ごとの変動が大きい） | fact（リクルート 2024） |

- 賃金構造基本統計調査は**10人以上の企業に雇われている人**の統計。1人オーナーとフリーランスは含まれない。
- **独立後の売上の試算**【estimate】：客単価7,686円（女性・2026年）×1日5人×月22日＝**月約84.5万円・年約1,015万円**（材料費・家賃・シェアサロン利用料を引く前）。シェアサロンで1〜3割を納める場合、手元に残るのは月59〜76万円（経費を引く前）。
- この売上に必要な**稼働中の顧客数**：年1,320回の来店 ÷ 1人あたり年4.18回 ＝ **約316人**【estimate】
- 1人あたりの来店が年0.1回減るだけで、316人なら年に約32回・**約24万円の減収**になる【estimate】

## 6. 客単価・来店周期・再来

**美容センサス2026年上期（調査期間2026/1/21〜2/12、15〜69歳、各6,600人）** 【すべて fact】

| 指標 | 女性 | 男性 |
|---|---|---|
| 市場規模 | 9,857億円（−4.7%） | 3,206億円（−9.5%） |
| 1年以内の利用率 | 77.5%（−1.7pt） | 32.7%（−1.8pt） |
| 1回あたり利用金額 | 7,686円（+0.2%） | 4,853円（−0.5%） |
| 年間利用回数 | 4.18回（−2.8%、3年連続で減少） | 5.05回（−3.6%） |
| 平均来店間隔（12か月÷回数） | **約87日**【estimate】 | **約72日**【estimate】 |
| 滞在時間 | 81分（−6分） | 49分（−4分） |
| ネット予約／電話予約 | 58.1%／19.5% | 52.1%／25.3% |
| いまのサロンに通い続ける理由の1位 | 「ネット予約できる」33.6% | 「ネット予約できる」32.3% |
| 利用が減った理由の1位（美容サロン全般） | 「美容代の節約」40.8% | 同 26.4% |

- 2025年上期と比べると、市場は1兆3,884億円（+2.5%）から縮小に転じた。2025年の女性客単価は7,668円【fact】
- 「また来たい」と最も強く思った場面が**来店前**だった人は、女性24.0%・男性32.3%。来店前の場面での1位は「ネット予約できる」、会計から帰宅後の場面での1位は「料金が明確・分かりやすい」（顧客満足調査2023）【fact】
- サロンを変えたいと思った瞬間は、施術32.7%、カウンセリング24.7%。次回の来店を見送りたくなる理由に「前回の施術内容を覚えていない」11.7%（40代では22.0%）（MOT調査2023/8。業界メディア経由）【fact（二次）】
- **新規客の再来率**「90日以内で約30%」はよく引用されるが、出典と調査年が示されていない。【unverified】信頼できる全国値は見つからなかった。

## 8. アプリへの示唆

1. **対象人数**【estimate】：1人の美容所が約8.5万施設、フリーランス・業務委託・シェアサロン利用者が数万〜8万人。合わせて**約10万〜17万人**が対象になる。最も伸びているのはシェアサロン利用者で、大手の拡大計画は1,000店舗規模。
2. **課金余地**【estimate】：月の売上が50〜85万円規模、採算はマイナス、価格転嫁も難しい。ツールに払える額は**月額1,000〜3,000円程度**が現実的で、無料版から始める設計が向く。「再来が年0.1回増えれば約24万円の増収」のように、ROIを数字で示す必要がある。
3. **解くべき問題**：
   - 来店間隔が延びている（女性は約87日、3年連続で悪化）→ 顧客ごとの次回来店の目安と、失客しそうな顧客へのアラート・リマインド
   - 顧客数の減少（問題点の1位、55.4%）と、約316人の稼働顧客を保つ必要 → 顧客台帳と再来率のKPI化
   - 値上げが難しい（42.6%）→ メニュー単価と値上げの影響の試算、料金をわかりやすく伝える支援
   - 「前回の施術を覚えていない」が離脱の一因 → 写真付きカルテ（薬剤・施術履歴）
   - ネット予約が6割で、通い続ける理由の1位 → 予約導線（外部の予約サイトやLINEとつなぐ）
   - 開業後の短命化 → 手取り（シェアサロンの歩合・経費を引いた後）の見える化
