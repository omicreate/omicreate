# 当事者の声：個人美容師の現場の困りごと（key: voices）

- 調査日: 2026-11-07
- 対象: 1人サロン経営者、フリーランス（業務委託・面貸し・シェアサロン利用者）
- 方法: WebSearch / WebFetch。note・Yahoo!知恵袋・X・業界メディア・事業者のプレスリリース・公的機関や調査機関の資料を確認した
- 種別の意味: **fact**＝本文を開いて確認した／**estimate**＝推定や二次情報からの計算／**unverified**＝検索結果の要約だけで、本文は確認していない

> **限界**: 「個人美容師だけ」に困りごとを聞いた全国規模の量的調査は見つけられなかった。そのため、以下の順位は「複数の出典に何度出てくるか（頻度）」と「収入や心身への打撃の大きさ（重さ）」を組み合わせた定性的な判断である。事業者の発信（シェアサロン、予約・集客ツールの会社）は自社サービスへの誘導を含むので、割り引いて読む必要がある。X の投稿は検索で拾える数が少なく、根拠としては弱い。

---

## 1. 要点

1. 一番大きい不安は**収入の不安定さ**。サロン経営者を対象にした2026年10月の調査では「経営上の最大の不安」の57.6%が「収入・利益の安定」、22.2%が「集客や顧客の維持」だった（fact、ただし美容師以外の業種も含む可能性あり）。
2. その原因として、**新規集客のコスト**（ホットペッパーの掲載料、Instagram 運用にかかる時間）と、**失客やリピートの維持**がくり返し語られている。
3. 日々の手間で目立つのは、**予約連絡が DM・LINE・電話・予約サイトに分かれていて、施術中は返せない**こと。
4. **無断・直前キャンセル**は、1人だと空いた枠がそのまま損失になる。キャンセル料を請求しづらく、回収もできないという声がある。
5. 経理・確定申告・インボイス、価格設定と値上げへの恐怖、業務委託先との関係、孤独・防犯・燃え尽き、体の負担は、頻度は中くらいだが、起きたときの打撃が大きい。

## 3. 観点別の声と根拠

### 3.1 収入の不安定さ（第1位）
- アトラパス株式会社「サロン経営者の働き方と暮らしに関するアンケート」（実施2026-10-21、公表2026-10-27、開業後の女性サロン経営者99人）。最大の不安は「収入・利益の安定」57.6%、「集客や顧客の維持」22.2%、「経営知識・スキル不足」2.0%（**fact**）。美容師に限った数字かどうかは未確認。
- 「固定給も最低保証もないので、売上がなければ収入はゼロ」「明日から切る人ゼロ」（脱職人＠カズ の note、2025-05-01、**fact**）。
- 独立1か月目の売上は30万円で、生活への不安から焦った。Instagram を分析して10か月で月100万円に到達した（kichi の note、2025-10-06、**fact**）。
- 月売上150万円・報酬率70%の業務委託美容師が「1人で独立したら手取りは減るか」と相談している。回答者たちは家賃しだいで厳しいという見方（知恵袋、2025-03-19、**fact**）。

### 3.2 新規集客（ホットペッパー・Instagram）
- SALOWIN（シェアサロン運営）は自社データとして、利用者の「最大の悩み」の上位3つを集客・客単価の伸び悩み・SNS運用の負担としている。平均客単価は13,000円（2025-05-24公開、2025-12-26更新、**fact**、件数の記載なし）。
- 掲載料が負担。99,000円のプランを半年続けると約60万円。プラン料金が約1万円から約2.7万円に上がったのをきっかけに無料プランへ移った（ふじこ の note、2026-03-07、まつ毛・ネイル系の個人サロン、**fact**）。
- 中心エリアの掲載費は月40万円を超え、予約経由のポイント手数料が2%かかる。やめると予約が止まるのが怖くて抜けられない（Hairbook CEO の note、2025-07-27、競合事業者の主張、**fact**）。
- 掲載料はエリアとプランで月2.5万〜50万円以上と幅がある（THE_MARKETING の note、**unverified**）。
- SNS投稿に時間を取られて施術との両立が難しい（カズ の note、**fact**）。独立後に一番苦労したのは Instagram に反応がない時期だった（kichi、**fact**）。

### 3.3 失客・リピート
- 新規100人のうち3回目まで来るのは平均30人で、70%は失客している（タカラベルモントの2009年データ。日本政策金融公庫「経営アドバイス」、ファイル名から2013年11月の資料と推定、**fact**。データは古い）。
- 「大幅に値上げしてから暇すぎる」「1年以上来ていないお客さんのカルテを抜く作業がつらい。常連さんも来なくなっていた」「値上げに恐怖を感じる」（1人美容室の女性店主 koko の note、2022-05-25、**fact**）。
- シェアサロン運営者のブログは、独立するときは最低でも2割の失客を見込むよう勧めている（GO TODAY、2022-04-15、**fact**、経験則で根拠なし）。

### 3.4 予約管理と連絡（DM・LINE・電話）
- 生活者の予約経路（美容センサス2025年上期、実査2025-01-27〜02-12、女性n≈5,200）: 電話21.0%、ネット予約計59.2%。ネット予約の内訳は予約サイト・アプリ（HPBなど）45.4%、サロンのホームページ6.1%、LINE7.4%、Instagram0.9%（**fact**）。経路が分かれていて、個人ではこれをまとめて管理しなければならない。
- 「施術後に40〜50件たまっている」「1件1分半なら50件で約75分」「定型文だと冷たく見えそうで、結局手で書く」（nksktk の note、2026-05-31、ツール開発者による発信、**fact**。数字は筆者の例示）。そのまま当てはめると1日約1時間、月約30時間の負担になる（**estimate**）。
- 「電話の間、いつもお客様をお待たせしてしまって本当に申し訳ない」（シマダアツシ＠一人サロン美容師 の note、2022-01-16、**fact**）。

### 3.5 無断・直前キャンセル
- リザービアの予約データ（2026年6月の全数集計）では、美容室のキャンセル率はお客様自身のWeb予約で17.24%（n=165,311）、店側の代理入力で15.36%、外部予約サイト経由で9.46%。ノーショー率（全業種）は代理入力4.87%、Web予約1.80%（**fact**）。
- 美容師の相談: HPB経由の予約客が来店せず、何度電話してもつながらない。後日支払うと約束したのにまた来ず、着信も拒否された。警察は民事なので動かない（知恵袋、2025-01-17、**fact**）。
- フリーランス施術者は「請求しづらい」「言いづらい」と心理的な負担を抱えている（SaNS のプレスリリース、2026-08-24、**fact**、調査データはなし）。
- 試算: 客単価13,000円の1人サロンで無断キャンセルが週1回あると、年間で約68万円の売上機会を失う（**estimate**）。
- キャンセル料の回収代行の依頼は美容系が想定以上に多い（弁護士ドットコムニュース、**unverified**）。

### 3.6 経理・確定申告・インボイス
- 確定申告・帳簿・経費管理・納税資金の確保をすべて自分でやる必要がある（カズ、**fact**）。集客・確定申告・材料の発注・予約管理を自分でやる（GO TODAY の note、2020-10-05、**fact**）。
- オーナー美容師の苦労として「税金の負担」「数字管理のためのPC入力や日報などの事務作業」（リジョブのアンケート記事、2018-08-10、**fact**、件数の記載なし）。
- 「初めての申告で、項目の基準などが全く分かりません」（税理士ドットコムの相談、**unverified**）。
- インボイス: 免税事業者への支払いについて、サロン側の仕入税額控除の経過措置は2026年10月から50%に縮小した。業務委託報酬の引き下げ圧力になりうる（解説記事、**unverified**）。
  - **訂正（統合時）**: この記述は誤り。国税庁リーフレット（令和8年9月）では、免税事業者からの仕入れの控除割合は 2026-10-01 から 80%→70%、2028-10-01 から 50%、2030-10-01 から 30%、2031-10-01 から 0%（05-rules.md の I4）。

### 3.7 価格設定・値上げ
- 2025年の美容室倒産は235件で、2年連続の過去最多。要因はコスト高・人手不足・値上げ難。倒産した店の9割超が資本金1000万円未満で、49.0%が設立から10年未満（帝国データバンク、2026-01-06、**fact**）。
- 値上げを怖がる声と、値上げの体験談を書いた note が多い（シマダ「7,000円→10,000円」など、**unverified**。検索要約で確認）。

### 3.8 業務委託先・サロンとの関係
- 退店時に顧客を転職先へ案内したいが、誓約書や損害賠償が心配（知恵袋、2022-06-22、**fact**）。
- 業務委託10年目の美容師。友人客の無理な要求を断りたいが、HPBや電話から予約されると店の都合で断れない（知恵袋、2026-03-28、**fact**）。
- シェアサロンは利用料に加えて技術売上の1〜3割を納める形が多く、「売上の上限が見える」（WWD JAPAN、2019-11-02、**fact**）。

### 3.9 孤独・燃え尽き・防犯
- 1人で約10年営業し、1日平均7人。「雇われていた頃は楽しかったのに、今は毎日が苦痛」「会話が面倒」（知恵袋、2024-05-22、**fact**）。
- 女性が1人で営業する店で、客からのつきまといや居座りがあり、愚痴のはけ口にされる。対策として閉店を早め、ボイスレコーダーや防犯カメラを置いた（koko の note、2022-02-01、**fact**）。
- 集客・人材育成・資金・税務・リスク管理など9つの要素を1人で同時に回す負担（FIVESTAR グループCEO の note、2025-10-31、**fact**。採用への誘導を含む）。

### 3.10 体の負担
- 理美容師の87%が手荒れに悩んでいる（東洋化学、2017-05-15に展示会で直接聴取、n=96、**fact**。古く、規模も小さい）。
- 前かがみの姿勢と薬剤の使用で、腰痛や皮膚炎になり離職した例がある（日本大学大学院の紀要、2012年、**fact**）。
- 個人美容師に限った最新の国内データは見つからなかった。

### 3.11 カルテ・材料
- 訪問した約10店舗はすべて紙カルテだった。理由は「書いた方が早い」「店にPCが1台しかない」（美歴の記事、2018-04-04、**fact**）。
- 面貸しでは薬剤も道具も自分で用意する（解説記事、**unverified**）。シャンプーやカラー材は値上がりしている（帝国データバンク、**fact**）。

## 4. アプリ設計への示唆（優先順）

1. **予約の窓口を一本化し、返信を半自動化する**: 空き枠リンク、DM・LINE用の返信テンプレート、施術中の自動応答。
2. **キャンセル対策**: リマインド、キャンセルポリシーへの同意記録、キャンセル待ちへの自動連絡。キャンセル料は「請求しづらい」を減らす文面と、外部決済との連携で扱う。
3. **失客アラート**: 来店周期から「そろそろの人」「離れかけの人」を一覧にし、次回予約を提案する。値上げシミュレーター（何%の失客まで許容できるか）も付ける。
4. **集客の費用対効果を見える化する**: HPB掲載料÷新規客数に加え、リピート率を考慮した実質的な獲得単価を出す。
5. **売上・経費の簡単な記録**: レシート撮影、業務委託報酬の計算（総売上と純売上の違い）、確定申告用の書き出し。
6. **カルテ**: スマホで写真・薬剤レシピ・履歴を記録し、音声メモで入力の手間を減らす。
7. 優先度は下がるが、**詰め込み防止**（休憩枠、最終受付時刻）、**要注意客メモ**（防犯・出禁）、**材料の残量メモ**。
8. 注意: 業務委託先を辞めるときの顧客データの扱いは契約しだいでトラブルになる。「個人の顧客台帳」が誰のものかを、規約と画面で明確にする必要がある。

## 5. 未確認・追加で調べるべきこと
- 個人美容師に限定した量的調査（困りごとの順位、予約経路の構成、キャンセル率）は見つからなかった。インタビューや自前のアンケートが必要。
- 生活者全体ではInstagram経由の予約が0.9%だが、個人美容師では DM の比率が高いと推測される（**estimate**）。裏付けはない。
- X の生の声はほとんど拾えなかった。
- HBA の就業実態調査（2024年）の転職理由は図表が画像のため、数値を読み取れなかった（「1位は給与への不満で4人に1人以上」という本文のみ確認）。
- 東京商工リサーチの「美容業の倒産120件（2025年）」は検索要約のみで、本文は未確認。
